# WSET Level 2 Wine Regions Map

An interactive study map of the wine regions, grapes and appellations covered in the WSET Level 2 Award in Wines, with tasting notes from class, exam tips, food pairings and grape profiles.

Open `index.html` through any web server (for example GitHub Pages). It loads `regions.js`, `extras.js` and `world.json` from the same folder.

Map outlines: Natural Earth (public domain) via the world-atlas package (ISC licence). Libraries: d3 and topojson-client (ISC), loaded from jsDelivr.
